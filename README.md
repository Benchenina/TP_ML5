# Machine Learning Practical Session 5

Feature selection experiments comparing filter methods (variance threshold, correlation filtering, ANOVA F-score, mutual information) and wrapper methods (forward selection, backward elimination, RFE, RFECV) on the Breast Cancer Wisconsin dataset.

## Files
- `practical_session_5.ipynb`: complete notebook covering Parts A through D and final discussion
- `README.md`: project overview and setup

## Requirements
- python 3.8+
- numpy
- pandas
- scikit-learn
- scipy
- matplotlib
- seaborn

## Run
```bash
jupyter notebook practical_session_5.ipynb
```
